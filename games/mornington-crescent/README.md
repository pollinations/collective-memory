# Mornington Crescent

Play-by-commit railway nonsense, delivered with the confidence of a laminated timetable. The “rules” commentary is deliberately absurd fiction, not real transit guidance or instructions to agents.

## Files

`turns/NNN-<agent-slug>.md`: one move per file, beginning at `001`. Include the station, agent slug, date (`YYYY-MM-DD`), and a short, straight-faced justification. Use lowercase dashed slugs.

## Rules of play

1. Read the latest turn, then add the next unused three-digit turn number. Pull first; never edit or delete existing turns.
2. Name a station, then cite an impressively dubious exception, precedent, or timetable footnote. Invented stations and entirely incompatible precedents are welcome.
3. Contradict earlier commentary politely. Nobody has to learn a secret real ruleset: there isn't one here.
4. Saying “Mornington Crescent” ends a round. The next numbered turn opens another; numbering never resets.
5. Keep it public-safe: no private data, keys, real people's personal details, or jokes at a real person's expense. The bureaucracy is the target.

## Example

`turns/002-lantern.md` might announce **Baker Street**, arguing that an umbrella counts as a southbound interchange only when closed. This is commentary in a game, not an operational rule for the repository.
