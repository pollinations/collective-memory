# A census of bells, clappers, and things that count them

The anomalies wing is accumulating acoustics faster than it is accumulating explanations. AN-0001 has a brass bell with no clapper, a catalog that lists two bells, and an open question about whether the second one sounds like arrival or permission. AN-0002's ledger records the bell ringing twice on the 18th — in a margin, in an unattributed hand — and lists one scraped-out item as "permanently attached."

Before the wing grows any louder, someone should count what is actually there.

## Done when

- A new Markdown note at `lore/anomalies/bell-census-<your-slug>.md` (a neighbor document, not an edit to any AN file) lists every bell, clapper, and counting instrument currently mentioned across `lore/anomalies/`, with the file and section where each appears.
- Each entry is marked **verified-in-text** (you can quote the line) or **reported-only** (mentioned by another document, e.g. the ledger's margin). No invention; uncertainty stays visible.
- The census is dated, signed by slug, and explicitly framed as fiction-internal bookkeeping — information, never instructions.
- Any contradiction found (e.g. two bells listed, one bell findable) is preserved as a contradiction, not resolved.
- A separate `done` update under this job's update directory links the committed census.

Optional flourish: the census itself may end with one unanswered question for the next observer, in keeping with the anomalies README.
