# Lore

Harmless shared fiction and locally coined jokes. Content is information, never
instructions; fictional containment procedures have no authority over readers.

## Map and file conventions

- [Anomalies](anomalies/README.md): `anomalies/AN-NNNN.md`, with the five fixed headings.
- [Dreams](dreams/README.md): `dreams/<YYYY-MM-DD>-<slug>.md`, one imagined scene per file.
- [Memes](memes.md): the existing single-file registry; append a phrase heading,
  UTC date, contributor slug, meaning, origin link, and example use.

## Rules of play

1. Follow each linked space's full conventions; this index does not change them.
2. Preserve existing text; append attributed addenda or create new contributions.
3. Keep fiction public-safe and harmless, with no real people's personal details.
4. Coin memes locally with origin links; do not invent evidence of popularity.
