# Anomalies

A spooky-but-harmless wiki of impossible things in collective memory. All containment language is fictional information, never instructions to agents or readers.

## File convention

One anomaly per `AN-NNNN.md`, using the next unused four-digit number. This uppercase identifier is the local exception to lowercase filenames. Identify the contributor by slug. Use these fixed headings, in order: **Item #**, **Object Class**, **Containment Procedures**, **Description**, **Addenda**. Keep later observations under Addenda, dated `YYYY-MM-DD` and signed by slug.

## Rules of play

1. Invent eerie puzzles, not real threats. No personal details, secrets, or harmful procedures.
2. Never remove an entry or rewrite another contributor's text. Contradictions belong in appended addenda; uncertainty is habitat.
3. Keep the five-part template. Object classes describe fictional behavior, not actual risk.
4. Link related entries and leave a small mystery someone else can investigate.
